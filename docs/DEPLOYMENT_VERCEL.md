# Запуск на Vercel

Локальная версия использует stdio и книгу на компьютере. В облаке Python-функция Vercel запускает готовый Excel MCP Server 2.3.2 со Streamable HTTP. Для каждого вызова функция скачивает нужную версию книги из приватного Supabase Storage во временный каталог.

Продакшен предоставляет таблицу и чат по защищённому адресу конкретного развёртывания Vercel. Для входа нужна Vercel Authentication команды. На публичном адресе виден интерфейс, а API рабочей области отклоняет запросы к книге и чату.

## Настройки проекта

1. Применить `supabase/workbook_storage.sql` в выделенном проекте Supabase. Исходная книга должна лежать в приватном бакете по пути `workbooks/requests.xlsx`. В приватной таблице `requests_private.workbook` сохранить SHA-256 выделенного токена записи.
2. В Vercel Production задать `MCP_MODE=http` и `MCP_HTTP_URL=https://excel-mcp-requests.vercel.app/api/workbook_mcp`. `MCP_HTTP_TOKEN` защищает обращение к Python-функции.
3. Задать `WORKBOOK_SUPABASE_PROJECT`, `WORKBOOK_SUPABASE_PUBLISHABLE_KEY` и `WORKBOOK_STORAGE_TOKEN`. Политика Storage разрешает читать исходную книгу по отдельному токену. `WORKBOOK_WRITE_TOKEN` используется для доступа к версиям книги и её SQL-функциям. Сохранить токены как серверные секреты.
4. Сохранить `OPENAI_API_KEY` как серверный секрет Production и установить `EXCEL_CLOUD_READ_ONLY=0`. Для режима чтения оставить `EXCEL_CLOUD_READ_ONLY=1` и не подключать токен записи. После изменения переменных развернуть проект заново.

## Хранение и проверки

MCP записывает по одному изменению в рабочую копию `requests.xlsx`. Функция загружает обновлённую книгу как `workbooks/versions/<uuid>.xlsx`. SQL подтверждает эту версию только при совпадении исходной версии с текущей и запоминает результат записи. Повтор операции получает прежний результат. План смены статуса хранится до пяти минут и привязан к сеансу, который его создал. Исходный файл остаётся в бакете как начальная версия. Копии версий накапливаются в бакете, автоматическая очистка пока не настроена.

Проверки локального MCP и адаптера Vercel можно запустить командами `npm test` и `.venv/bin/python -m unittest discover -s tests -p 'workbook_mcp_test.py'`. Для проверки облака открыть защищённый адрес развёртывания, обновить таблицу, найти заявку через чат и проверить, что карточка подтверждения смены статуса привязана к текущему сеансу.
