# Подготовка к Vercel

Локальная версия использует stdio и книгу на компьютере. Для размещения требуется доступный извне Excel MCP Server с постоянным диском. Vercel Functions могут включать файлы в сборку, а запись в их временную файловую систему привязана к экземпляру. [Файлы в Vercel Functions](https://vercel.com/kb/guide/how-can-i-use-files-in-serverless-functions) · [Хранение состояния серверных функций](https://vercel.com/i/serverless-container-storage)

## Путь развёртывания

1. Разместить Excel MCP Server 2.3.2 на одном процессе в контейнере или VM с постоянным томом. Закрепить версию образа и запустить со строгим `--allow-dir /srv/workbooks`. Книга лежит на томе. Настроить резервные копии и процедуру проверки восстановления.
2. Вынести сервер за TLS-прокси. Настроить `EXCEL_MCP_AUTH_TOKEN`, заголовок `Authorization: Bearer …` и доступ только для авторизованных вызовов. Ограничить входящий трафик по возможностям хостинга. Проверить работу HTTP-сессий и потоковой передачи через прокси.
3. Перед открытием приложения добавить вход для сотрудников и ограничения частоты запросов. Перенести планы, короткую историю и идемпотентность в постоянное хранилище с TTL. Хранилище должно поддерживать атомарное потребление плана и блокировку записи по книге между репликами. В локальной версии маршрут закрыт в окружении Vercel до реализации этого слоя.
4. Задать на Vercel серверные `OPENAI_API_KEY`, `OPENAI_MODEL`, `MCP_MODE=http`, `MCP_HTTP_URL`, `MCP_HTTP_TOKEN`, `EXCEL_FILE_PATH=requests.xlsx` и секреты хранилища/авторизации. MCP-адаптер уже поддерживает HTTP и проверяет схему URL. Внешнее соединение требует HTTPS и Bearer-токен.
5. Проверить права доступа, OpenAI, три сценария, отмену, устаревший план, повтор запроса, параллельные подтверждения, обновление страницы и перезапуск MCP с сохранённой книгой.

Варианты инфраструктуры для согласования — VM с подключённым диском или контейнерный хостинг с постоянным томом, TLS-прокси, KV/SQL для серверного состояния. Оценку затрат и конкретные сервисы можно определить после согласования размещения.
