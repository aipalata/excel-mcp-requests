# Отчёт о проверках

Проверено 20 ноября 2026 на macOS. Использованы Node.js 24, Python 3.12, Next.js 16.4.6, OpenAI SDK 7.62.0, Excel MCP Server 2.3.2 и Chrome. Приложение проверено на `127.0.0.1:3000`.

| Проверка | Статус | Что наблюдалось |
|---|---|---|
| Исходный Excel, лист «Заявки» | Пройдено | Книга создана и оформлена через MCP. Прочитаны №101, №102, №103 |
| Запрос каталога | Пройдено | `initialize` принят, `tools/list` вернул 26 инструментов |
| Добавление №104 и защита от повтора | Пройдено на уровне приложения и MCP | Два параллельно отправленных вызова одной операции дали одну строку. Статус «Новый» проверен повторным чтением |
| Предпросмотр, отмена и изоляция плана | Пройдено на уровне приложения и MCP | Excel до подтверждения совпал с исходным снимком. Чужая сессия и вторичное решение отклонены |
| Подтверждение, чтение и сохранность данных | Пройдено на уровне приложения и MCP | В `write_range` ушла только D5. Остальные поля и строки совпали, результат сохранился после открытия нового соединения |
| Фильтр «В работе» после сценария | Пройдено на уровне приложения и MCP | На тестовой книге прочитаны №102 и №104 |
| №999, совпадающие имена и устаревший план | Пройдено на уровне приложения и MCP | №999 и изменение строки после подготовки плана не вызвали запись. Совпадения вернули два номера для уточнения |
| Нет описания или передана формула | Пройдено | Серверная проверка отклонила недопустимые поля до записи. В запросе через OpenAI без описания модель задала уточняющий вопрос |
| Сброс демоданных | Пройдено | На отдельной книге восстановлены три исходных записи, повторное чтение совпало |
| Кнопка обновления и таблица | Пройдено в Chrome | Реальный `read_range`, три строки, фильтр, вставка команды и статус без ключа |
| Трассировка и схема | Пройдено в Chrome | Из журнала раскрыты аргументы A1:D4 и ответ MCP. Проверены переключение шагов, воспроизведение, пауза и сброс |
| Адаптивность | Пройдено в Chrome | 1440 и 390 CSS px. На мобильном экране ширина документа совпала с viewport. Системное уменьшение движения отключило анимацию |
| HTTP API приложения | Пройдено | Без ключа чат сообщает об отсутствии настройки и не вызывает инструменты. Неизвестный план, другой Origin и некорректный запрос отклонены |
| MCP недоступен | Пройдено | Неверная команда запуска дала понятную ошибку соединения |
| Streamable HTTP на loopback | Пройдено | Без токена сервер вернул HTTP 401, с токеном выполнил каталог и чтение №101–103 |
| TypeScript, production build | Пройдено | `npm run typecheck`, `npm run build`, запуск через `npm start`. Для сборки использован webpack после ошибки локального сокета Turbopack |
| Диалог с реальной моделью | Пройдено через локальный API | `gpt-5-mini` обработала команды на отдельной книге. Проверены создание №104, отмена плана, смена статуса после подтверждения, выборка №102 и №104, отсутствующая заявка №999 и запрос без описания |

Автоматический набор `npm test` завершился с 13 успешными проверками, включая родительский интеграционный тест. Все изменения в сценариях выполнялись на отдельном временном `.xlsx`, а в [data/requests.xlsx](../data/requests.xlsx) сохранены исходные три заявки. [Фактическая трассировка](MCP_TRACE.md)

## Облачная версия и учебная схема

| Проверка | Что наблюдалось |
|---|---|
| Облачный чат и Excel MCP | На защищённом адресе Vercel агент нашёл №102 и добавил учебную заявку №104. После подтверждения статус №104 изменился на «В работе» |
| Сохранность после перезагрузки | В открытой заново облачной версии прочитана заявка №104 со статусом «В работе». В Supabase зафиксированы две операции записи |
| Переключение учебной схемы | Локально показано подключение по stdio, облачный вариант проходит 16 шагов до контрольного чтения. Режим «Выполнение» открывает реальные вызовы `read_range` |
| Схема на Vercel | «Vercel + Supabase» выбран по умолчанию. В браузере проверен шаг подтверждения версии PostgreSQL. Журнал зафиксировал фактический `read_range` |
