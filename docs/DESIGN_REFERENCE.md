# Визуальная система занятия 9

Референс — приложенный статичный PDF «Занятие 9. AI-агенты с инструментами», 55 слайдов. Просмотрены все страницы. Шаги воспроизведения разработаны по последовательности кадров презентации.

| Слайды | Что перенесено в приложение |
|---|---|
| 1–3 | Светлый фон, выразительный заголовок, бирюзовый акцент, пиктограммы в белых карточках |
| 4, 28 | Рабочая область из примеров, чата и данных |
| 5–6, 23–26, 53–55 | Имена функций моноширинным шрифтом, каталог и выбор инструмента |
| 7–18, 32–45 | Участники на общей линии, направленные стрелки, активный шаг, техническая карточка |
| 19–22 | Пиктограммы приложения, модели, MCP-клиента, сервера и файла. Ключевое действие выполняет приложение по просьбе модели |
| 39–42, 48 | Карточка плана, явное подтверждение, отдельный шаг чтения после записи |
| 46–52 | Цветовые роли протоколов и внешних систем |

Фон, базовый текст и пастельные роли сняты с растеризации слайдов 1, 5, 6, 12 и 41. Акценты для текста затемнены для читаемости. Заголовки набраны Roboto Condensed Variable размером 33–56 px для титула и 23–41 px для разделов. Интерфейс использует Golos Text Variable с кириллицей. Инструменты и JSON используют системный моноширинный шрифт. Оба веб-шрифта поставляются локально через Fontsource и лицензированы по OFL. Радиусы панелей 20 px, внутренних карточек 9–12 px. Основной разрыв между панелями 15 px. Мягкая тень оставляет границы карточек различимыми на светлом холсте.

Интерактивная схема использует CSS и пиктограммы Lucide. При переключении шага CSS проявляет стрелку за 220 мс. Автовоспроизведение запускается кнопкой и останавливается при ручной навигации. При `prefers-reduced-motion` подсветка меняется сразу. В режиме «Выполнение» стрелка показывает событие из журнала. Внутреннее обращение сервера к файлу показано в учебной схеме.

На широких экранах схема и журнал занимают равные колонки с общей верхней и нижней границей. Подробности прокручиваются внутри журнала. На узких экранах схема и журнал идут друг под другом, а таблица переходит под чат.
