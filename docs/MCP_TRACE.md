# Трассировка

Браузер получает NDJSON из `POST /api/workspace`. Событие начинается со статуса «выполняется» и обновляется по паре ID операции и номер шага. Каждый элемент содержит время, статус, измеренную длительность и доступные параметры, результат или ошибку. Журнал хранит последние 180 шагов в пределах открытой страницы.

- «Схема» показывает учебный сценарий смены статуса. Переключатель «Локально» / «Vercel + Supabase» показывает, где работает MCP и как сохраняется книга. На Vercel по умолчанию открыт облачный вариант.
- «Выполнение» подсвечивает участника и направление по выбранному фактическому событию.
- «Журнал MCP» показывает `initialize`, `tools/list` и `tools/call`. Переключатель с пиктограммой кода включает события модели и интерфейса. Раскройте строку, чтобы увидеть JSON.
- Абсолютные пути, токены и URL скрываются перед отправкой в браузер. Внутренние рассуждения модели в журнале отсутствуют.

При чтении через кнопку «Обновить данные» приложение получает каталог и диапазон через MCP. При сообщении в чате после получения каталога приложение передаёт разрешённые схемы модели. Событие о выборе функции добавляется при фактическом получении `function_call`. После ответа инструмента приложение отправляет `function_call_output`. При подтверждении статуса приложение сверяет и выполняет сохранённый план.

В облачном варианте схема выделяет скачивание и сохранение `.xlsx` в Storage и проверку текущей версии в PostgreSQL. Журнал показывает общий вызов MCP, внутри которого выполняются эти действия. [Облачный запуск](DEPLOYMENT_VERCEL.md)

## Фактический вызов при проверке через stdio

Событие от 20 ноября 2026 в 12:32:55 по Москве, операция `7de3f66f-38d5-49e0-8fa8-37a4e76e99fc`, шаг 4. Статус успешный, длительность 6 мс.

```json
{
  "method": "tools/call",
  "name": "read_range",
  "arguments": {
    "sheet": "Заявки",
    "range": "A1:D4",
    "max_cells": 4004,
    "path": "requests.xlsx"
  }
}
```

Зафиксированный ответ инструмента:

```json
{
  "range": "A1:D4",
  "values": [
    ["ID", "Клиент", "Проблема", "Статус"],
    [101, "Иван Петров", "Ноутбук не включается", "Новый"],
    [102, "Мария Соколова", "Принтер не печатает", "В работе"],
    [103, "Олег Иванов", "Мерцает монитор", "Готово"]
  ]
}
```

В интеграционном тесте на отдельной книге запись после согласования вернула обновлённую строку №104. Аргументы фактического `write_range` проверялись отдельным утверждением.

```json
{
  "at": "D5",
  "rows": [["В работе"]],
  "sheet": "Заявки",
  "path": "requests.xlsx"
}
```

При проверке с `gpt-5-mini` в потоке локального API также зафиксированы ответы модели и успешные вызовы MCP при добавлении №104, чтении и смене статуса после подтверждения. Полный сценарий выполнен на отдельной тестовой книге. [Результаты проверки](TEST_REPORT.md)
