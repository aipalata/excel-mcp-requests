# AI-агент «Заявки»

Одностраничная мастерская ремонта компьютеров. Сотрудник пишет команду по-русски, OpenAI выбирает функцию, приложение проверяет параметры и обращается к готовому Excel MCP Server. Рабочая книга [data/requests.xlsx](data/requests.xlsx) содержит три вымышленные заявки.

## Выбор MCP-сервера

Выбран Excel MCP Server 2.3.2 от Haris Musa. Он работает с локальным `.xlsx` через stdio, ограничивает доступ папкой проекта и умеет читать диапазоны, добавлять записи и менять отдельные ячейки. На тестовой книге проверены лист «Заявки», запись и повторное чтение после переподключения. [Критерии выбора и результаты проверок](docs/MCP_SELECTION.md)

## Продолжить разработку на этом Mac

В корне проекта с установленными зависимостями запустите `npm run dev` и откройте [127.0.0.1:3000](http://127.0.0.1:3000). Next.js отслеживает изменения в исходниках и обновляет страницу при сохранении. Интерфейс находится в `app/`, работа с Excel MCP и OpenAI — в `lib/`. Для остановки сервера нажмите Ctrl+C в терминале, где он запущен.

## Запуск на macOS

Нужны Node.js 22.9 или новее и Python 3.11 или новее. Для Excel MCP Server проверен Python 3.12.

```bash
npm ci
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-mcp.txt
cp -n .env.example .env.local
npm run dev
```

Откройте [приложение на 127.0.0.1:3000](http://127.0.0.1:3000). При первом открытии приложение читает книгу через MCP. Таблица, фильтры, кнопка обновления и журнал работают без ключа. Если распаковали исходники без книги, создайте её командой `npm run excel:init`.

### Подключение чата

Создайте ключ в настройках своего проекта OpenAI Platform. Откройте `.env.local` в локальном редакторе и впишите ключ в значение `OPENAI_API_KEY`. Перезапустите сервер. Этот файл исключён из Git и архива. Ключ хранится на сервере. [Ключи OpenAI Platform](https://platform.openai.com/api-keys)

По умолчанию используется `gpt-5-mini`. В `OPENAI_MODEL` можно указать другую доступную в проекте модель с Responses API, function calling и поддержкой строгих схем. [Документация gpt-5-mini](https://developers.openai.com/api/docs/models/gpt-5-mini)

### Сценарий для преподавателя

1. На исходной книге отправьте «Добавь заявку от Анны Смирновой: ноутбук сильно тормозит». Ожидается №104 со статусом «Новый».
2. Отправьте «Измени статус заявки Анны Смирновой на „В работе“». Проверьте карточку плана. Для проверки отмены нажмите «Отменить», затем отправьте команду снова и подтвердите. Ожидается запись только в D5.
3. Отправьте «Покажи все заявки со статусом „В работе“». Ожидаются №102 и №104.
4. Проверьте запросы про заявку №999 и новую заявку от Дмитрия без описания поломки.
5. В журнале MCP выберите нужную операцию и раскройте `write_range` и контрольный `read_range`.

### Команды

| Команда | Назначение |
|---|---|
| `npm run mcp:tools` | Получить каталог `tools/list` с фактическими схемами |
| `npm run excel:init` | Создать и заполнить отсутствующую демонстрационную книгу |
| `npm run excel:reset -- --yes` | Вернуть три исходные заявки через MCP. Удаляет добавленные строки и изменения статусов. Перед сбросом остановите приложение и сохраните нужные данные |
| `npm run typecheck` | Проверить типы TypeScript |
| `npm test` | Проверить операции с отдельной книгой и реальным MCP |
| `npm run build && npm start` | Собрать и запустить production-сборку локально |
